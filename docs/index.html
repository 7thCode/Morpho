Morpho

隠れマルコフモデル(HMM)による日本語形態素解析デスクトップアプリ

macOS Apple Silicon / Intel (universal) .zip をダウンロード
Windows 64bit (x64) .zip をダウンロード
Linux 64bit (x64) .zip をダウンロード

過去のリリース一覧は Releases から確認できます。

主な機能

  • 文字種境界でのトークン分割 + HMMによる品詞推定
  • コーパスからの学習によるモデル精度向上
  • 辞書ブラウザ（単語の追加・編集・削除）
  • File > Open... / Write... によるテキストファイルの読み込み・分かち書き書き出し

使い方

インストール方法や各タブの操作、Fileメニューの使い方は使い方マニュアルを参照してください。
