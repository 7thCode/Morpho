Morpho

HMMで日本語を解析する、外部送信なしのネイティブデスクトップアプリ

外部依存ゼロ(Go標準ライブラリのみ) 学習で精度が向上 解析はすべてローカル完結
macOS Apple Silicon / Intel (universal) .zip をダウンロード
Windows 64bit (x64) .zip をダウンロード
Linux 64bit (x64) .zip をダウンロード

過去のリリース一覧は Releases から確認できます。

主な機能

文字種 + HMM解析

文字種境界でトークンに分割し、HMM(隠れマルコフモデル)がViterbiアルゴリズムで文全体として自然な品詞列を推定します。未学習時は文字種・語尾パターンによるヒューリスティックに自動フォールバック。

しくみを図解で見る →
コーパス学習

学習用テキストを読み込ませると遷移確率・出力確率が更新され、単語ごとの出現傾向と品詞の並び方を反映した解析に近づきます。複数回学習させるとコーパスは累積されます。

学習の仕組みを見る →
辞書ブラウザ

登録済み単語を検索・並べ替えしながら、表層形・品詞・出現頻度を直接編集できます。プロジェクトやコーパスごとに辞書ファイルを切り替えることも可能です。

File > Open... / Write...

テキストファイルを読み込んでそのまま解析し、結果を分かち書き(スペース区切り)としてファイルへ書き出せます。⌘/Ctrl+O / ⌘/Ctrl+S のショートカットにも対応。

Goライブラリとして使う

デスクトップアプリの土台になっている解析エンジンは、外部依存ゼロの単体Goライブラリとしても公開しています。 

go get github.com/7thCode/morpho
pkg.go.dev で見る プレイグラウンドで試す
