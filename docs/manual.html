1. インストールと起動

  1. トップページからOS向けの .zip をダウンロードします。
  2. zipを展開すると Morpho.app(macOS)/ Morpho.exe(Windows)/ Morpho(Linux)が出てきます。
  3. そのまま実行(macOSはダブルクリック、Windows/Linuxは実行ファイルを起動)します。

macOS: 「開発元を確認できません」と表示される場合

配布物はApp Store配布用の公証(Notarization)を受けていないため、初回起動時にGatekeeperの警告が出ることがあります。 Morpho.app を右クリック(またはControl+クリック)して「開く」を選択すると、確認ダイアログ経由で起動できます。一度許可すれば以降は通常のダブルクリックで起動できます。

Windows: SmartScreenの警告が出る場合

署名付きコード証明書を使っていないため、初回実行時にSmartScreenの警告が出ることがあります。「詳細情報」→「実行」で起動できます。

2. 画面構成

ウィンドウ上部に3つのタブがあります。

タブ できること
解析 日本語テキストを形態素解析し、品詞構成比と単語ごとの品詞を表示
学習 (Train) コーパス(学習用テキスト)からHMMモデルを学習し、解析精度を向上
辞書ブラウザ 辞書に登録されている単語の検索・追加・編集・削除

右上には辞書単語数と、モデルが学習済み(HMM)かヒューリスティック(未学習)かのステータスが常に表示されます。

3. 解析タブ

  1. テキストエリアに解析したい日本語文章を入力します。入力するたびに自動で(デバウンス付きで)再解析されます。
  2. 「再解析」ボタンでも手動実行できます。⌘/Ctrl + Enter でも実行可能です。
  3. 結果は「品詞の構成比」(棒グラフ)と、単語ごとの表層形・品詞を一覧表示する表の2カラムで表示されます。
結果テーブルは表示負荷を抑えるため最初の1,000語まで表示します。それ以上ある場合はテーブル下部に「表示件数が多いため最初の1,000語のみ表示しています」と表示されます(解析結果の件数自体・品詞構成比は全語数が対象です)。

4. 学習(Train)タブ

  1. 学習用のコーパス(通常の文章、またはスペース区切りで 単語/品詞 の形式)をテキストエリアに入力します。
  2. 「サンプル文章を読込」ボタンで、動作確認用のサンプルコーパスを読み込めます。
  3. 「学習を実行・保存」を押すと、遷移確率・放出確率がHMMモデルに反映され、辞書ファイルに保存されます。

学習が完了すると、右上のステータスが「学習済み (HMM)」に変わり、解析タブでの精度が向上します。

5. 辞書ブラウザ

  • 上部の検索ボックスで単語または品詞から絞り込み、プルダウンで品詞フィルタもかけられます。
  • 各列見出しをクリックするとその列でソートされます(昇順/降順の切り替えも可能)。
  • 「単語を追加」ボタンから新しい単語(表層形・品詞・出現頻度)を辞書に登録できます。
  • 一覧の各行にある編集/削除アイコンから、既存エントリーの修正・削除ができます。

辞書ファイルの変更

辞書ブラウザ上部の「現在の辞書ファイル」パネルにある「変更」ボタンから、別の dict.json を選択または新規作成できます。プロジェクトやコーパスごとに辞書を使い分けたい場合に利用してください。

6. Fileメニュー(Open... / Write...)

メニュー ショートカット 動作
File > Open... ⌘/Ctrl + O テキストファイルを選択して読み込み、解析タブに反映して自動解析します。
File > Write... ⌘/Ctrl + S 直前の解析結果を分かち書き(スペース区切り)テキストとして保存します。

「Write...」は解析タブで解析済みの結果が必要です。何も解析していない状態で実行すると「書き出す解析結果がありません」と表示されます。

7. よくある質問

Q. 解析結果の品詞が思った通りにならない

未学習の状態では文字種・語尾パターンによるヒューリスティック推定にフォールバックします。学習タブでコーパスを学習させると、統計的なHMMモデルによる推定に切り替わり精度が上がります。

Q. 辞書データはどこに保存されている？

辞書ブラウザの「現在の辞書ファイル」に表示されているパスの dict.json に、単語エントリーと学習済みモデルがJSONで保存されます。

Q. 長い文章を解析すると重い

解析処理自体は文字数に比例した時間で完了しますが、結果テーブルの表示は前述の通り最初の1,000語までに制限されています。それ以上のボリュームを一括で確認したい場合は、File > Write... で分かち書きをファイルに書き出してご利用ください。
